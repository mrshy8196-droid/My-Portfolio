# 🌟 Black & Gold Luxury Portfolio

A responsive, high-performance personal portfolio website built with semantic HTML5 and custom CSS3. Designed with a modern **Black & Gold** aesthetic to showcase projects, skills, and personal information with an executive finish.

---

## ✨ Features

- **Responsive Design:** Optimized for all screen sizes (Desktop, Tablet, and Mobile devices).
- **Black & Gold Theme:** Elegant dark mode theme featuring glowing borders and smooth hover transitions.
- **Projects Showcase:** Highlighted key development projects with direct links to live demos and source repositories.
- **Contact Integration:** Functional protocols for direct email (`mailto:`) and social media links (LinkedIn, GitHub).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture for better accessibility and structure.
- **CSS3:** Custom styles utilizing Flexbox, Grid, Media Queries, and CSS Animations.
